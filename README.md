## Wemory 能做什么

Wemory 面向希望在自己的电脑上整理微信资料的用户。应用在本机读取和处理微信数据，帮助你集中浏览并按需导出：

- 聊天记录：浏览私聊、群聊和企业会话，导出为 HTML 或 PDF。
- 朋友圈：按时间浏览朋友圈内容，导出为 HTML 或 PDF。
- 通讯录：查看联系人，并将联系人和群成员导出为 XLSX。
- MCP 服务：让本机 AI 客户端通过 MCP 读取聊天、联系人与朋友圈数据。
- 批量语音转文字：把会话里的语音批量识别为可搜索、可导出的文字。

## 本地优先

微信数据的读取、解密和导出默认均在本机完成，不上传聊天数据或用户信息。联网仅用于应用更新及下载必要组件；唯一的例外是「批量语音转文字」：只有你主动开启并确认授权后，所选语音的音频才会逐条发送到你自己配置的阿里云百炼接口。音频内容无法脱敏，使用前请确认自己有权处理这些语音。导出文件由你自行选择保存位置。

## 聊天记录导出

Wemory 会将微信会话按好友、群聊和企业会话分类，支持搜索、类型筛选和批量选择。你可以在导出前直接浏览消息内容，并按日期范围导出指定会话。

![Wemory 群聊记录浏览界面](assets/wemory-chat-list.png)

聊天记录支持文本、图片、视频、语音、表情、附件和折叠消息等常见类型。图片使用原图导出，未下载的视频也会显示封面，便于离线查看和归档

## MCP 功能

Wemory 可以作为本机 MCP 服务运行，让支持 MCP 的 AI 客户端读取你本机已有的聊天记录、联系人和朋友圈数据。在「设置 → AI 工具 → MCP 服务」开启服务，设置一个固定端口（例如 38471），状态显示「运行中」即可使用。

![Wemory MCP 服务设置](assets/wemory-mcp-settings.png)

服务只监听 `127.0.0.1`，访问令牌不要公开或写入日志。仓库提供 [`wemory-mcp-setup/SKILL.md`](wemory-mcp-setup/SKILL.md)，可让 AI 自动发现本机连接、生成 Codex 或 WorkBuddy 的客户端配置（写入前备份原有配置），并验证服务是否正常。

![Wemory MCP 配置与验证结果](assets/wemory-mcp-install-result.png)

连接后可以直接向 AI 提问，例如「查找我和张三最近 20 条聊天记录」。MCP 只读取本机已有数据，不修改微信数据；具体可用工具以客户端连接结果为准。

![通过 MCP 分析聊天记录](assets/wemory-mcp-analysis.png)

## 批量语音转文字

微信客户端只能逐条手动把语音转成文字。Wemory 支持选定一个会话和日期范围，一次性把尚未转成文字的语音交给语音识别服务处理，结果回填到聊天气泡，并可用于会话搜索、导出、归档和后续分析。

![Wemory 语音转文字设置](assets/wemory-speech-settings.png)

目前支持阿里云百炼（通义千问）的语音识别模型，提供两种接入方式：

- 按量付费：支持 `qwen-audio-3.0-asr-flash` 与 `qwen-audio-3.1-asr-flash`，可选北京（默认）或新加坡地域，使用对应地域的普通百炼 API Key。
- Token Plan：使用套餐专属地址，仅支持 `qwen-audio-3.0-asr-flash`，使用 `sk-sp-` 开头的套餐 API Key。

![添加语音识别配置](assets/wemory-speech-add-config.png)

开始转写前可先「预检」：它只读取本地消息，显示待转写条数和预计总时长，不上传音频。确认后再勾选授权并启动；单次最多转写 1,000 条，范围内超过 20,000 条时需要缩小日期范围。任务可在「任务中心 → 语音转文字」查看进度、日志和失败明细，并暂停、继续、取消或重试失败项。

![批量转写预检](assets/wemory-speech-preview.png)

完成后语音气泡会显示「阿里云转写」文本，可手动校正。已生成的导出文件与历史分析不会自动改写。配置里的「测试」只发送一段内置样音，不读取聊天语音，但可能产生少量费用；API Key 通过 Windows DPAPI 加密保存在本机。

![转写结果](assets/wemory-speech-transcript.png)

## 下载与安装

1. 前往 [Releases](https://wemory.chituhub.com) 下载
2. 在 Windows 10 或 Windows 11 x64 上运行安装程序。
3. 启动 Wemory，按照界面提示连接本机微信数据目录。

当前安装包尚未使用 Windows 代码签名证书签名，因此系统可能显示 Microsoft Defender SmartScreen 提示。
